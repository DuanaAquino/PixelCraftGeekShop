##🛍️ PixelCraft | Geek E-commerce UI

PixelCraft is a responsive front-end e-commerce interface designed for a geek/gamer audience. The project showcases a modern UI with a strong visual identity, focusing on usability, layout consistency, and interactive elements.

---

##🚀 Overview

This project simulates an online store featuring handmade geek products such as collectibles, accessories, and themed items. It was built to demonstrate front-end development skills, including layout structuring, responsive design, and basic interactivity using JavaScript.

---

##✨ Features
Responsive layout (desktop and mobile)
Interactive product carousels
Dropdown navigation menu with smooth transitions
Promotional banner with dynamic positioning
Product cards with pricing, discount display, and CTA
Newsletter subscription section
Structured footer with multiple content sections
Clean and consistent UI for e-commerce usability

---

##🧱 Tech Stack
HTML5 – semantic structure
CSS3 – custom styling, flexbox, responsiveness
JavaScript (Vanilla) – UI interactions (carousels)
Google Fonts – Poppins, Orbitron, Nunito
Font Awesome – icons

---

##🎯 Key Highlights
Built from scratch without frameworks
Focus on component-like structure (cards, navbar, sections)
Emphasis on UX/UI consistency
Use of flexbox and responsive media queries
Custom carousel logic using JavaScript

---

##📱 Responsive Design

The layout adapts for smaller screens using media queries, simplifying navigation and restructuring components for better mobile usability.
